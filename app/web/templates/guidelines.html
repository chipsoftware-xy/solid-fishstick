How to Use Spark

Starting and stopping calls — Start begins a call; only the very first one reloads everything (Whisper, Piper, Gemma), every call after that reuses what's already loaded. Stop ends the current call after the exchange in progress finishes — it won't cut Spark off mid-sentence.

Watching a call happen — the Live Transcript box on the main page fills in turn by turn while a call is active. Once the call ends, refresh the page to see the "Last call" summary (status, name, company, callback time).

Working your scheduled callbacks — History lists every call that ended with a callback scheduled. Check off the ones you've actually called back, then hit "Confirm callbacks done" to clear them out.

Reviewing past calls — Review Conversations shows the last 5 calls with full transcripts. Dataset shows everything, grouped by outcome (Scheduled / Rejected / Incomplete), with delete controls for cleaning up old data.

Choosing what Spark targets — Tune Spark (under Settings) lets you pick which kind of business Spark is calling on behalf of. Only the Employee ID campaign is fully built right now — the other verticals are on the menu but not wired up yet, coming soon.

Changing the voice — Set Voice picks from whichever Piper voices are downloaded. Changes apply on the next reload — use "Stop Gemma" then Start, or a full restart.
